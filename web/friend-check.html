Why approval is required

A webpage cannot silently inspect your computer

Browsers are intentionally isolated from operating-system commands, logs, services, WSL and network configuration. NetTrace uses a readable PowerShell checker that the device owner must review and run explicitly.

Browser-safe device diagnostics

Limited by browser sandbox

This mode can report browser/OS hints, logical CPU threads, approximate memory where supported, screen capabilities, site-storage quota, network-quality hints, battery state and browser features. It cannot access BIOS, serial numbers, firmware, installed applications, Windows services, logs, WSL, private files or network configuration.

    Run with consent

    Open PowerShell in the download folder and run:

    pwsh -NoProfile -File .\friend-device-check.ps1
